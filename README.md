# גלאי אקורדים (Chord Sense)

אתר שמאפשר להעלות שיר או קובץ סאונד ולקבל את רצף האקורדים שלו — **כל הניתוח מתבצע בדפדפן**, בלי שרת ובלי שליחת הקובץ לשום מקום.

Upload a song or audio file and get its chords — analyzed entirely in your browser. No server, no uploads.

## תכונות

- העלאת MP3 / WAV / M4A / OGG / FLAC (גרירה או בחירה)
- זיהוי אקורדים מז'ור/מינור לאורך זמן, עם חותמות זמן
- נגן מסונכרן — האקורד הנוכחי מודגש בזמן אמת, כולל הצצה לקודם/הבא
- ציר זמן אינטראקטיבי של אקורדים + Waveform עם דילוג בלחיצה
- זיהוי סולם משוער (Krumhansl–Schmuckler)
- טרנספוזיציה של כל האקורדים בחצאי טונים
- ממשק בעברית (RTL), עיצוב כהה עם אקצנט ניאון

## איך זה עובד

1. **פיענוח** — `OfflineAudioContext` מפענח את הקובץ וממיר למונו ב-22,050Hz
2. **STFT** — חלון Hann בגודל 8192, הופ 2048, בעזרת `fft.js`
3. **כרומה (HPCP)** — מיפוי תדרים ל-12 מחלקות צליל עם דחיסה לוגריתמית
4. **התאמת תבניות** — מתאם פירסון מול 24 תבניות אקורד (12 מז'ור + 12 מינור)
5. **מיזוג** — איחוד מקטעים זהים והסרת מקטעים קצרים מדי

## טכנולוגיות

React 19 · TypeScript · Vite · Tailwind CSS · Web Audio API · fft.js

## הרצה מקומית

```bash
npm install
npm run dev
```

בנייה לפרודקשן:

```bash
npm run build
```

## מבנה הקוד

```
src/
├── lib/chordEngine.ts    # מנוע הניתוח: DSP, כרומה, זיהוי אקורדים וסולם
├── pages/Home.tsx        # ניהול מצבי האפליקציה (העלאה → ניתוח → תוצאות)
└── components/
    ├── UploadZone.tsx    # אזור גרירה והעלאה
    ├── AnalysisView.tsx  # מסך התוצאות: אקורד ענק, waveform, רשימה, טרנספוזיציה
    ├── ChordStrip.tsx    # פס אקורדים אופקי מסונכרן
    ├── Waveform.tsx      # ציור waveform על canvas עם דילוג
    └── PlayerBar.tsx     # נגן זכוכית קבוע בתחתית
```
